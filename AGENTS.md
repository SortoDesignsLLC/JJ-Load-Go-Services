# Project guidance

This is the JJ Load & Go Services website, using Next.js App Router, TypeScript, and Tailwind CSS.

- Preserve the business identity, phone number, service details, and responsive layout.
- Keep images in `public/images` and icons in `public`.
- Run `npm run lint`, `npm run typecheck`, and `npm run build` before delivery.
- Do not rewrite published Git history.
